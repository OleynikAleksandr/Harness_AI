# VS Code Link Opener Module

## Responsibility

Open absolute workspace file links in Visual Studio Code.

## Public Facade

`VsCodeLinkOpenerFacade`

## Inputs

- Absolute file path.
- Optional line and column.

## Outputs

- VS Code open result.
- User-visible failure state when the path cannot be opened.

## Owned Paths

- `module.md`
- `src/**`
