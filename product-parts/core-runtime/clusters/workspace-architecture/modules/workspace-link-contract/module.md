# Workspace Link Contract Module

## Responsibility

Emit file-link targets for Application Shell and VS Code opening.

## Public Facade

`WorkspaceLinkContractFacade`

## Inputs

- Workspace path.
- Relative file target and optional position.

## Outputs

- Absolute file link payload.
- Link validation diagnostics.

## Owned Paths

- `module.md`
- `src/**`
